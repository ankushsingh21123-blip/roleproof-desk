# RoleProof Python + PostgreSQL

AI-assisted portfolio extension of the existing RoleProof React ticket desk, not an employer assessment. Substantial AI assistance was used for implementation, debugging and testing. Synthetic data only. No claim of unaided user authorship.

Status: live Python deployment verified 17 Nov 2026 at https://roleproof-python.vercel.app/ . Health identifies Python Flask and direct scoped Supabase PostgreSQL. Existing Next/Node variants remain separate and unchanged.

Python Flask calls the existing isolated portfolio PostgreSQL RPC directly over HTTPS using a publishable key. It does not proxy the Node backend. The database schema is `../schema.postgres.sql`. No service-role key or database password is needed. Each Python browser gets a new independent random workspace cookie (SHA256 only sent to the database). The RPC enforces private schema access, isolation, atomic updates, 500 total active workspaces, 40 tickets/workspace, 20 writes/minute and seven-day expiry. Existing Node demo sessions are not reused.
